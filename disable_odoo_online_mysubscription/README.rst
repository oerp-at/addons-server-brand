Bridge between ``disable_odoo_online`` and the Odoo core module
``mysubscription`` (auto-installed since 20.0).

On Community, it removes the "My Subscription" item from the user menu.
That dashboard links to odoo.com pricing and editions. On Enterprise the
item is kept, like the update notifier in ``disable_odoo_online``.
